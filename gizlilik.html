🩺 Doktormust Gizlilik Politikası

Son güncelleme: 14 Ekim 2026

TürkçeEnglish← Oyuna dön
Kısaca: Doktormust hiçbir kişisel bilgi toplamaz. Oyunda reklam, satın alma, izleme ya da analiz aracı yoktur. Oyunun kaydı yalnızca oynandığı cihazda durur.

1. Toplanan bilgiler

Doktormust çocuklar için yapılmış, kurgusal bir doktorluk oyunudur. Oyun bize ya da başka bir şirkete hiçbir bilgi göndermez. Hesap açmak için e-posta, telefon numarası ya da gerçek ad istenmez.

2. Cihazda saklananlar

Oyunun çalışması için şu bilgiler yalnızca oynandığı cihazda saklanır (tarayıcının yerel deposunda ya da Android uygulamasının kendi klasöründe):

  • Oyuncunun kendi seçtiği takma ad, doktor görünümü ve klinik adı,
  • oyun ilerlemesi (seviye, yıldızlar, çıkartmalar, rozetler),
  • ayarlar (dil, ses, süre sınırı) ve ebeveyn PIN'i,
  • Arkadaş Skorları tablosuna oyuncunun kendisinin yazdığı adlar ve skor kodları,
  • ebeveyn uygulamasıyla eşleşme anahtarı (eşleştirildiyse).

Bu bilgiler cihazdan dışarı çıkmaz. Silmek için oyundaki profil silme düğmesini kullanabilir, tarayıcının site verilerini temizleyebilir ya da uygulamayı kaldırabilirsiniz.

3. Paylaşım

Oyun hiçbir şeyi kendiliğinden paylaşmaz. Ebeveyn raporu bağlantısı ve haftalık skor kodu, yalnızca oyuncu ya da ebeveyn kendisi kopyalayıp birine gönderirse paylaşılır. Rapor bağlantısı bilgileri bağlantının içinde taşır; bir sunucuya kaydedilmez.

4. Android uygulaması ve izinler

Android uygulaması internet izni istemez; oyun tamamen telefonun içinden açılır. Kullandığı izinler:

  • Titreşim: doğru ya da yanlış kartta kısa titreşim için (Ayarlar'dan kapatılabilir),
  • Bildirim: yalnızca ebeveyn günlük hatırlatmayı açarsa,
  • Açılışta çalışma: telefon yeniden başlayınca bu hatırlatmayı yeniden kurmak için.

Sesli okuma, telefonun kendi seslendirme motoruyla cihazda yapılır.

5. Web sürümü

Oyunun web sürümü GitHub Pages üzerinde yayınlanır. Sayfayı açtığınızda GitHub, sitenin çalışması ve güvenliği için IP adresi gibi teknik kayıtlar tutabilir. Bu kayıtlar bize gelmez; ayrıntılar için GitHub Gizlilik Bildirimi'ne bakabilirsiniz. Oyunun kendisi çerez kullanmaz.

6. Çocuklar

Oyun çocuklar için yapılmıştır ve çocuklardan kişisel bilgi toplamaz. Oyundaki sağlık bilgileri geneldir; kart eşleşmeleri gerçek tedavi önerisi değildir. Gerçekten hasta olan bir çocuk bir büyüğüne ve doktora başvurmalıdır.

7. Değişiklikler ve iletişim

Bu politika değişirse güncel hâli bu sayfada yayınlanır. Sorularınız için Google Play'deki uygulama sayfasında yazan geliştirici e-posta adresine yazabilirsiniz.

🩺 Doktormust Privacy Policy

Last updated: 14 October 2026

In short: Doktormust collects no personal information. The game has no ads, no purchases and no tracking or analytics tools. Game progress stays only on the device where it is played.

1. Information we collect

Doktormust is a pretend doctor game made for children. The game sends no information to us or to any other company. No email address, phone number or real name is needed.

2. Stored on the device

To work, the game stores the following only on the device where it is played (in the browser's local storage or in the Android app's own folder):

  • the nickname, doctor look and clinic name the player chooses,
  • game progress (level, stars, stickers, badges),
  • settings (language, sound, time limit) and the parent PIN,
  • names and score codes the player types into the Friend Scores table,
  • the pairing key for the parent app (if paired).

This information never leaves the device. To delete it, use the delete profile button in the game, clear the browser's site data, or uninstall the app.

3. Sharing

The game never shares anything by itself. A parent report link or a weekly score code is shared only if the player or parent copies it and sends it to someone. The report link carries its information inside the link; it is not saved on any server.

4. Android app and permissions

The Android app does not ask for internet access; the game runs entirely from the phone. Permissions it uses:

  • Vibration: a short buzz on right or wrong cards (can be turned off in Settings),
  • Notifications: only if a parent turns on the daily reminder,
  • Run at start-up: to set the reminder again after the phone restarts.

Read-aloud uses the phone's own text-to-speech engine on the device.

5. Web version

The web version is hosted on GitHub Pages. When you open the page, GitHub may keep technical logs such as IP addresses to run and protect the site. We do not receive these logs; see the GitHub General Privacy Statement. The game itself uses no cookies.

6. Children

The game is made for children and collects no personal information from them. Health facts in the game are general; card matches are not real medical advice. A child who is really ill should tell a grown-up and see a doctor.

7. Changes and contact

If this policy changes, the new version will be published on this page. For questions, write to the developer email shown on the app's Google Play page.
